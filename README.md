# Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors Game** developed using HTML, CSS, and JavaScript. Play the classic hand game against the computer and test your luck!

## Project Overview

This project recreates the classic Rock Paper Scissors game as a browser-based application. It uses JavaScript to handle game logic, generate computer choices, and determine the result of each round.

The project demonstrates fundamental frontend development concepts, including DOM manipulation, event handling, conditional logic, and random number generation.

## Features

- **Interactive Gameplay:** Choose between Rock, Paper, and Scissors.
- **Computer Opponent:** Computer generates a random move.
- **Game Logic:** Automatically determines win, lose, or draw.
- **Dynamic Results:** Displays the result after each round.
- **User-Friendly Interface:** Simple and easy-to-use game interface.
- **Real-Time Interaction:** Play multiple rounds directly in the browser.

## Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and layout
- JavaScript – Game logic and interactivity

## Game Rules

| Player Choice | Beats |
|---|---|
| Rock | Scissors |
| Paper | Rock |
| Scissors | Paper |

If both the player and computer select the same option, the round ends in a draw.

## Getting Started

```bash
git clone https://github.com/bhartisharma7/Rock-Paper-Scissor-Game.git
```

### 2. Navigate to the Project Folder

```bash

```

### 3. Run the Game

Open the `index.html` file in your preferred web browser.

No additional dependencies or installations are required for a basic HTML, CSS, and JavaScript implementation.

## How to Play

1. Open the game in your browser.
2. Select Rock, Paper, or Scissors.
3. The computer randomly selects its move.
4. View the result of the round.
5. Continue playing and enjoy the game!
